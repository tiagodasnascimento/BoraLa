# BoraLá

Aplicativo de descoberta de eventos em bares e restaurantes, com agenda diária e status de movimentação.

## Estrutura do projeto

- `frontend/` - aplicação mobile em Flutter
- `backend/` - API e serviços em Elixir
- `docker-compose.yml` - ambiente local com containers

## Requisitos

- Flutter SDK
- Elixir + Erlang/OTP
- Docker

## Próximos passos

1. Instalar Flutter e Elixir.
2. Executar `flutter pub get` dentro de `frontend`.
3. Executar `mix deps.get` dentro de `backend`.
4. Iniciar os serviços com Docker Compose.
